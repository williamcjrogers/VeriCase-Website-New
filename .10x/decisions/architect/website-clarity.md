# Website clarity: investigation and proposal

Status: proposed, 01 October 2026.

The failure was an over-broad simplification: short summaries replaced detailed explanations, and useful source inspection was removed with confusing illustrations. A stale open tab additionally showed an older release. These are separate findings. The visual dissatisfaction remains a design judgement requiring review of a concrete revision.

Retain the current React architecture and content gates. Restore existing prose in readable full-width sections, using a short overview for orientation. A small shared source-inspection pattern should connect dated events or argument citations to the existing fictional excerpts. No server, AI service, route or dependency is needed. Essential explanations remain visible. Prefer inline disclosure over nested panels; preserve focus and provide an explicit close or toggle state.

Rejected extremes: reinstating the whole simulated walkthrough; making every example entirely static; hiding all substantive material in accordions. All repeat the mismatch with the owner's brief.

Next: concrete Superdesign proposal, user review, then one bounded implementation with browser evidence. No new implementation approval has been recorded for this revised proposal.
